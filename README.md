## About Me

I'm a Web Programming student at **Anadolu University**, focused on software development, cybersecurity, and understanding how computer systems work.

My primary interests include **web application security, network technologies, Linux, secure backend development, and penetration testing**.

I enjoy learning through hands-on laboratories, building software projects, and documenting the technical concepts I explore.

My long-term goal is to become a skilled cybersecurity professional with a strong foundation in software engineering and computer science.

> "Understand the system. Question its assumptions. Build it securely."

- **Penetration Testing:** Reconnaissance, enumeration, vulnerability assessment

- **Network Security:** TCP/IP, DNS, routing, switching, network analysis
- **Backend Security:** Authentication, authorization, JWT, secure APIs
- **Security Automation:** Python scripting and security tooling
